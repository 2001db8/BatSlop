# Privacy Policy

BatSlop does not collect, transmit, sell, or share personal data.

## Data Collection

BatSlop does not collect analytics, browsing history, account information, Reddit content, or any other personal data.

The extension does not send data to external servers and does not use remote code.

## Local Extension Settings

BatSlop uses the browser extension storage API to save extension settings, including:

- whether the extension is enabled
- whether the optional "All of Reddit" mode is enabled
- configured target subreddits
- configured text replacement rules

Depending on the browser, these settings may be stored locally or synced by the browser vendor as part of the browser's own extension sync feature.

## Reddit Page Access

BatSlop runs only on Reddit domains declared in the extension manifest. It reads and modifies page content in the browser so it can rewrite matching post titles and replace matching preview images.

This processing happens locally in the browser. BatSlop does not send Reddit page content anywhere.
